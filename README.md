# 🌐 Social Media Hub — User-Managed Credentials

A Streamlit dashboard where **each user enters their own API credentials**
for Facebook, Instagram, Twitter/X, TikTok, LinkedIn, and YouTube.
Nothing is stored server-side — everything lives in the browser session.

## 🎯 Features

- 🔑 **User enters their own credentials** — no admin keys needed
- 🔐 **Session-only storage** — disappears when the tab closes
- 🌐 **Optional proxy** — route API calls through your VPN's proxy endpoint
- 💾 **Export / Import session** — save and restore your settings
- 📊 **Connection summary** with masked credentials
- 🧪 **Network test** to verify connectivity

## 🚀 Deploy in 5 minutes

```bash
git init social-media-hub
cd social-media-hub
# copy the files above
git add .
git commit -m "Initial Social Media Hub"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/social-media-hub.git
git push -u origin main
```

Then go to [share.streamlit.io](https://share.streamlit.io) → **Create app** →
select your repo → **Deploy**. No secrets configuration required.
